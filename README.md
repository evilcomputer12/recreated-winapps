# Recreated native macOS apps — Calculator & Paint

Native SwiftUI/AppKit recreations of Windows Calculator and Paint, grounded in the
reverse-engineering in `../REPORT.md` (Calculator's view-model set; Paint's tool set — with
**all generative-AI features omitted**).

## Build & run

`xcode-select` points at CommandLineTools on this machine, so point builds at the full Xcode
explicitly with `DEVELOPER_DIR`:

```bash
cd Calculator        # or Paint
xcodegen generate                       # regenerate the .xcodeproj from project.yml
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -scheme Calculator -configuration Release -derivedDataPath build CODE_SIGNING_ALLOWED=NO
open build/Build/Products/Release/Calculator.app
```

Or just open `Calculator.xcodeproj` / `Paint.xcodeproj` in Xcode and press ⌘R.
(Projects are generated by XcodeGen from `project.yml`; edit the yml, not the pbxproj.)

## Calculator  (`Calculator/`)
Sidebar app (⌘1–⌘5 switch modes). View-models mirror `CalcViewModel.dll`. Full feature audit in `FEATURES.md`.
- **Standard** — immediate-execution, memory (MC/MR/M+/M−/MS), history popover
- **Scientific** — full precedence parser, DEG/RAD/GRAD, `2nd` inverse, **HYP hyperbolic** (sinh/cosh/tanh ±inv), log/ln, powers, roots, n!, π/e
- **Programmer** — HEX/DEC/OCT/BIN live, **word size QWORD/DWORD/WORD/BYTE** with masking, **clickable bit-toggle grid**, AND/OR/XOR/NOT, **NAND/NOR**, LSH/RSH, **RoL/RoR**, mod
- **Graphing** — plot up to 3 `y=f(x)` equations, pan (drag) + zoom, auto grid/axes (shared expression evaluator)
- **Date Calculation** — difference between dates; add/subtract Y/M/D
- **Converters** — 12 categories
- **Keep on top** (⇧⌘T), hardware-keyboard input throughout (local `NSEvent` monitor).
- Engine logic is unit-tested: `swiftc -O Sources/Engines.swift calctest.swift && ./a.out` (16 checks).

## Paint  (`Paint/`)
Layer-based AppKit `NSBitmapImageRep` canvas inside a magnifiable `NSScrollView`, with a
Windows-11-Paint-style command bar (Clipboard · Tools · Brushes · Shapes · Size · Colours · Image · Layers).
Full feature audit in `FEATURES.md`.
- **Tools:** rectangular select **+ free-form (lasso)**, pencil, **brushes** (Brush, Marker, Watercolour, Crayon, Calligraphy, Oil), airbrush, eraser, fill (flood), colour picker, text
- **Selection:** move, **8 resize handles (resize pasted/selected images)**, cut/copy/paste, delete, transparent selection, select-all; live selection size in status bar
- **Text:** font family / size / bold / italic / colour (format bar appears with the Text tool)
- **Shapes gallery (18):** line, **polygon (multi-click)**, rect, rounded-rect, ellipse, triangles, diamond, pentagon, hexagon, 5/6-point star, 4 arrows, heart, **lightning** — Outline / Fill / Both
- **Image menu:** rotate 90° L/R, **180°**, flip H/V, crop to selection, invert colours, **resize image (resample)** + resize canvas
- **View:** **gridlines + rulers** toggle, zoom slider
- **Layers panel:** add / duplicate / delete / reorder / merge-down, per-layer visibility + opacity
- **Clipboard:** cut / copy / paste (⌘X/⌘C/⌘V); **Undo/redo** (⌘Z / ⇧⌘Z, 30 steps)
- Primary + secondary colour (left vs right mouse), click-to-target palette
- **Native file open/save** (PNG/JPEG/TIFF/**BMP/GIF** via `NSOpen/SavePanel`).
- Build note: `Paint --snapshot <out.png> [--demo]` renders the window to a PNG headlessly (used to verify UI).

Both apps are ad-hoc signed (`CODE_SIGN_IDENTITY = -`); they run locally. To distribute, sign with a
Developer ID.
